## Как это работает

### Мобильная версия (< 768px)
1. Пользователь видит нижнюю навигацию с 4 кнопками
2. Нажимает кнопку "Связь" 💬
3. Открывается модальное окно с контактами
4. Может выбрать:
   - WhatsApp (открывается мессенджер)
   - Телефон (открывается приложение для звонков)
   - Просмотреть адрес и режим работы
5. Закрывает окно кнопкой X или кликом вне окна

### Десктопная версия (≥ 768px)
1. Пользователь видит раздел "Связь с нами" в футере
2. Все контакты доступны напрямую
3. Нижняя мобильная навигация скрыта

## Технические детали

### ContactModal
```typescript
interface ContactModalProps {
  isOpen: boolean;
  onClose: () => void;
}
```

**Анимации**:
- Backdrop: fade in/out
- Modal: scale + fade + slide up
- Transition: spring (0.3s)

**Z-index**:
- Backdrop: z-[80]
- Modal: z-[90]

### MobileNav
```typescript
const [contactModalOpen, setContactModalOpen] = useState(false);
```

**Управление состоянием**:
- `onClick={() => setContactModalOpen(true)}` - открыть
- `onClose={() => setContactModalOpen(false)}` - закрыть

## Проверка работы

### 1. Конфигуратор товара
```bash
1. Откройте сайт
2. Перейдите в каталог
3. Откройте первый товар
4. Прокрутите вниз до блока "Цена"
5. Увидите конфигуратор с вариантами и опциями
6. Выберите цвет, размер, сборку
7. Цена обновится автоматически
8. Добавьте в корзину
9. Откройте корзину - конфигурация сохранена
```

### 2. Модальное окно контактов (мобильная версия)
```bash
1. Откройте сайт на мобильном устройстве или в DevTools (< 768px)
2. Прокрутите вниз до нижней навигации
3. Нажмите кнопку "Связь" 💬
4. Откроется модальное окно с контактами
5. Проверьте все ссылки:
   - WhatsApp (должен открыться мессенджер)

6. Закройте окно кнопкой X или кликом вне окна
```

### 3. Скрытие раздела в футере (мобильная версия)
```bash
1. Откройте сайт на мобильном устройстве (< 768px)
```
