## 1. Кнопки (Buttons)

### Primary Button (Основная)
```
┌─────────────────────────┐
│   Добавить в корзину    │  ← bg: #22C55E (зелёный)
│                         │     text: белый
│                         │     padding: 12px 24px
└─────────────────────────┘     border-radius: 12px
                                font-weight: 600
                                hover: scale 1.05
```

### Secondary Button (Вторичная)
```
┌─────────────────────────┐
│      В избранное        │  ← bg: #F5F5F7 (светло-серый)
│                         │     text: #1D1D1F (чёрный)
│                         │     padding: 12px 24px
└─────────────────────────┘     border-radius: 12px
                                hover: bg #E5E5E5
```

### Outline Button (Контурная)
```
┌─────────────────────────┐
│      Подробнее          │  ← bg: transparent
│                         │     border: 2px solid #E5E5E5
│                         │     text: #1D1D1F
└─────────────────────────┘     hover: border #22C55E
```

### Icon Button (С иконкой)
```
┌──────┐
│  🛒  │  ← 42x42px
│      │     border-radius: 12px
└──────┘     hover: bg #F5F5F7
```

## 🎯 Состояния компонентов

### Кнопка
- **Default:** обычное состояние
- **Hover:** scale 1.05, изменение цвета
- **Active (tap):** scale 0.95
- **Disabled:** opacity 0.5, cursor not-allowed
- **Loading:** спиннер внутри

### Поле ввода
- **Default:** border серый
- **Focus:** border зелёный, ring
- **Error:** border красный
- **Disabled:** bg серый, cursor not-allowed
- **Success:** border зелёный, галочка

### Карточка товара
- **Default:** обычное состояние
- **Hover:** поднимается, увеличивается тень
- **Active:** в корзине (зелёная галочка)
- **Out of stock:** opacity 0.6, метка "Нет в наличии"

## 📱 Адаптивные правила

### Текст
- **Desktop:** 16px base
- **Mobile:** 14px base

### Отступы
- **Desktop:** 32px между секциями
- **Mobile:** 16px между секциями

### Сетка товаров
- **Desktop:** 4 колонки, gap 24px
- **Tablet:** 3 колонки, gap 16px
- **Mobile:** 2 колонки, gap 12px

### Кнопки
- **Desktop:** height 44px, padding 12px 24px
- **Mobile:** height 48px (больше для тапа), padding 14px 20px

---

## ✨ Финальные штрихи

1. **Все интерактивные элементы** должны иметь hover и active состояния
2. **Минимальный размер тапа** на мобиле: 44x44px
3. **Контраст текста:** минимум 4.5:1 для обычного текста, 3:1 для крупного
4. **Скругления:** единообразные (12px для большинства элементов)
5. **Тени:** мягкие, не резкие
6. **Анимации:** плавные, не дольше 0.5s
7. **Иконки:** 20-24px, stroke-width 1.5-2
