### 3. ✅ Опция "Сборка мебели"

**Что сделано:**
- Добавлено поле `assemblyPrice` в тип `Product`
- Цены сборки заданы для всех товаров:
  - Кровати: 3000-3500 ₽
  - Шкафы: 4500 ₽
  - Столы: 1500-2000 ₽
  - Кресла: 1500 ₽
  - Беседки: 15000 ₽
  - Тумбы: 1000 ₽
- Toggle переключатель с анимацией
- Реактивный пересчет итоговой цены
- Детализация цены при включении сборки:
  - Товар: X ₽
  - Сборка: Y ₽
  - Итого: Z ₽
- Иконка гаечного ключа (Wrench)
- Плавные анимации появления/исчезновения

**Технические детали:**
- State: `assemblySelected` (boolean)
- Расчет: `finalPrice = basePrice + (assemblySelected ? assemblyPrice : 0)`
- useMemo для оптимизации
- Framer Motion для анимаций

**Файлы:**
- `src/data/products.ts` (обновлен тип + данные)
- `src/pages/ProductPage.tsx` (добавлена логика)

### 4. ✅ Гибкая цена сборки (Admin-ready)

**Что сделано:**
- Цена сборки хранится в данных товара (`assemblyPrice`)
- НЕ захардкожена в коде
- Легко изменяется через:
  - Админ-панель (когда будет реализована)
  - API backend
  - JSON конфигурацию
- Опциональное поле (товары без сборки просто не имеют этого поля)

**Структура данных:**
```typescript
export type Product = {
  // ... другие поля
  assemblyPrice?: number; // Опционально
}
```

**Пример:**
```typescript
{
  id: "p1",
  name: "Кровать «Альмак»",
  price: 48000,
  assemblyPrice: 3500, // Задается админом
  // ...
}
```

## 📝 Примечания

### Lightbox:
- Использует `position: fixed` для полноэкранного режима
- Блокирует скролл body через `overflow: hidden`
- z-index: 100 (выше всех элементов)
- Поддерживает Escape для закрытия

### Цена сборки:
- Опциональная (не все товары требуют сборку)
- Легко расширяется (можно добавить другие опции)
- Реактивная (мгновенное обновление UI)
- Admin-ready (готово к интеграции с админкой)

### Header:
- Sticky positioning (остается вверху при скролле)
- Glassmorphism эффект
- Динамическая тень при скролле
- Полностью адаптивный
