```typescript
// Admin Routes
<Route path="/admin" element={<AdminDashboard />} />
<Route path="/admin/products" element={<ProductsManagement />} />
<Route path="/admin/products/new" element={<ProductEdit />} />
<Route path="/admin/products/edit/:id" element={<ProductEdit />} />
```

### Навигация:
```
/admin                          → Dashboard
/admin/products                 → Список товаров
/admin/products/new             → Создать товар
/admin/products/edit/:id        → Редактировать товар
```

## 📚 Инструкция по использованию

### Для администратора:

1. **Открыть админку:**
   ```
   https://ваш-сайт.vercel.app/admin
   ```

2. **Просмотр статистики:**
   - Откройте Dashboard
   - Посмотрите метрики
   - Проверьте алерты

3. **Управление товарами:**
   - Перейдите в "Товары"
   - Используйте поиск и фильтры
   - Редактируйте или удаляйте товары

4. **Добавление товара:**
   - Нажмите "Добавить товар"
   - Заполните форму
   - Нажмите "Создать товар"

5. **Редактирование товара:**
   - Найдите товар в списке
   - Нажмите иконку редактирования
   - Измените данные
   - Нажмите "Сохранить изменения"
