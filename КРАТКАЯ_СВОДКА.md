## 🚀 Что делать дальше

### 1. Проверьте локально
```bash
npm install
npm run dev
```

Откройте DevTools → Console и проверьте логи:
- `[Web Vitals] CLS: ...`
- `[Analytics] Ecommerce - view_item`

### 2. Настройте мониторинг
Добавьте в `.env.production`:
```bash
VITE_GA_MEASUREMENT_ID=G-XXXXXXXXXX
VITE_SENTRY_DSN=https://xxx@xxx.ingest.sentry.io/xxx
```

### 3. Соберите и задеплойте
```bash
npm run build
npm run preview  # проверка
# Затем деплой на Railway/Vercel/Render
```
