## ❓ ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

### Проблема: Ошибка при git push

**Решение:**
```bash
git pull origin main
git push origin main
```

### Проблема: Конфликты при pull

**Решение:**
1. Открыть файлы с конфликтами
2. Выбрать нужную версию
3. Выполнить:
```bash
git add .
git commit -m "merge: resolve conflicts"
git push origin main
```

### Проблема: Нужно откатить изменения

**Решение:**
```bash
git reset --soft HEAD~1  # Откатить коммит, но сохранить изменения
```

## 💡 СОВЕТ

Для добавления конфигурации к товару:

1. Открыть `src/data/products.ts`
2. Добавить поле `configuration`:

```typescript
{
  id: "product-01",
  name: "Товар",
  price: 50000,
  // ... остальные поля
  configuration: {
    variants: [
      {
        id: "color",
        label: "Цвет",
        type: "color",
        required: true,
        options: [
          { value: "black", label: "Черный", priceModifier: 0 },
          { value: "white", label: "Белый", priceModifier: 2000 },
        ],
      },
    ],
    options: [
      {
        id: "assembly",
        label: "Сборка мебели",
        type: "toggle",
        price: 3500,
      },
    ],
  },
}
```
