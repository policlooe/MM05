## 🛠️ Скрипты и конфигурация (3 файла)

### 8. scripts/generate-sitemap.ts
**Назначение:** Генератор динамического sitemap из БД  
**Использование:**
```bash
npm run generate:sitemap
```

**Автоматически запускается при:**
```bash
npm run build
```

**Что делает:**
- Читает товары из БД
- Генерирует sitemap.xml с актуальными URL
- Добавляет lastmod (дата последнего изменения)
- Сохраняет в public/sitemap.xml

---

### 9. public/_headers
**Назначение:** Security headers для Vercel  
**Содержит:**
- Content-Security-Policy (CSP)
- X-Frame-Options: DENY
- X-Content-Type-Options: nosniff
- Referrer-Policy
- Permissions-Policy

**Применяется автоматически** при деплое на Vercel

---

### 10. public/site.webmanifest
**Назначение:** Web App Manifest для PWA  
**Содержит:**
- Название приложения
- Иконки (SVG, PNG)
- Цвета темы
- Режим отображения (standalone)
- Категории (shopping, lifestyle)

**Используется:** Android устройствами при добавлении на главный экран
