### ✅ 3. ЗАЩИТА ОТ ПЕРЕПРОДАЖИ

**Механизм:**
- Транзакция PostgreSQL
- Row-level locking (SELECT FOR UPDATE)
- Проверка наличия перед списанием
- Атомарность операций

**Гарантия:**
- Два клиента не могут купить последний товар одновременно
- Товар резервируется сразу при создании заказа
- При ошибке все изменения откатываются

### ✅ 4. СОЗДАНИЕ ЗАКАЗА

**Генерация номера:**
- Формат: MM05-YYYY-XXXX
- Пример: MM05-2026-0001
- Автоинкремент по годам

**Статусы:**
```
NEW → RESERVED → CONFIRMED → PROCESSING → SHIPPED → DELIVERED → COMPLETED
                                                                    ↓
                                                                CANCELLED
```

### ✅ 5. НАКЛАДНАЯ (INVOICE)

**Формат:** HTML (готов к печати)

**Содержимое:**
- Номер заказа и дата
- Информация о клиенте (ФИО, телефон, email, адрес)
- Список товаров с ценами
- Дополнительные опции (сборка и т.д.)
- Итоговая сумма
- Комментарии клиента и менеджера

**Дизайн:**
- Брендированный (цвета MM05)
- Адаптивный (desktop + mobile)
- Готов к печати (@media print)

### ✅ 11. ДОПОЛНИТЕЛЬНЫЕ ЗАЩИТЫ

1. **Защита от двойного клика**
   - Кнопка disabled во время отправки
   - Loading состояние

2. **Idempotency**
   - Уникальные номера заказов
   - Невозможно создать дубликат

3. **Валидация данных**
   - Frontend: Zod схема
   - Backend: Zod схема + Prisma

4. **Логирование**
   - Успешные операции: `✅ Order created`
   - Ошибки: `❌ Order creation error`

5. **Обработка ошибок**
   - Недостаток товара: HTTP 409
   - Валидация: HTTP 400
   - Общие ошибки: HTTP 500
