## 🎨 Минималистичный дизайн

### Принципы:

#### 1. Тонкие рамки
```css
border-border/60  /* Вместо border-border */
```
Более легкий, воздушный вид.

#### 2. Плавные переходы
```css
hover:border-accent/30  /* Тонкий акцент */
hover:bg-accent/5       /* Легкий фон */
```
Ненавязчивые hover эффекты.

#### 3. Градиенты для важных блоков
```css
from-accent/5 to-accent/10  /* Легкий градиент */
```
Выделяет важные секции без агрессии.

#### 4. Увеличенные отступы
```css
py-3.5  /* Вместо py-3 */
px-4    /* Вместо px-3 */
```
Больше воздуха, легче читать.

#### 5. Тени для выбранных элементов
```css
shadow-sm  /* Легкая тень */
```
Добавляет глубину без перегрузки.

## 🎯 Детали реализации

### 1. Заголовок блока

```typescript
<div className="bg-gradient-to-br from-accent/5 to-accent/10 border border-accent/20 rounded-xl p-4">
  <h3 className="text-base font-semibold text-foreground mb-1">
    Дополнительные опции
  </h3>
  <p className="text-xs text-muted-foreground">
    Настройте товар под свои потребности
  </p>
</div>
```

### 2. Заголовок секции

```typescript
<button className="w-full flex items-center justify-between px-4 py-3.5 hover:bg-accent/5 transition-colors group">
  <div className="flex items-center gap-2 flex-1 min-w-0">
    <h3 className="text-sm font-medium text-foreground group-hover:text-accent transition-colors">
      {group.label}
      {group.required && <span className="text-accent ml-1">*</span>}
    </h3>
    {selectedOption && !isExpanded && (
      <span className="text-xs text-muted-foreground truncate">
        — {selectedOption.label}
      </span>
    )}
  </div>
  <ChevronDown className="w-4 h-4 text-muted-foreground group-hover:text-accent" />
</button>
```

### 3. Кнопка опции

```typescript
<button className={cn(
  "relative px-4 py-3 rounded-lg border text-sm transition-all text-left",
  "flex flex-col gap-1.5 min-h-[60px]",
  isSelected
    ? "border-accent bg-accent/10 text-accent shadow-sm"
    : "border-border/60 bg-white hover:border-accent/50 hover:bg-accent/5"
)}>
  <span className="font-medium text-sm leading-tight break-words">
    {option.label}
  </span>
  {option.priceModifier !== 0 && (
    <span className="text-xs font-semibold">
      {option.priceModifier > 0 ? '+' : ''}{formatPrice(option.priceModifier)}
    </span>
  )}
</button>
```

### 4. Итоговая цена

```typescript
<div className="bg-gradient-to-br from-accent/5 to-accent/10 border border-accent/20 rounded-xl p-4 sticky bottom-0 shadow-lg">
  <div className="flex items-center justify-between mb-2">
    <h3 className="text-sm font-semibold text-foreground">
      Итоговая стоимость
    </h3>
    <button className="text-xs text-accent hover:text-accent-hover font-medium">
      {expandedSections['price-details'] ? 'Скрыть детали' : 'Показать детали'}
    </button>
  </div>
  
  {/* Детализация (если развернута) */}
  
  <div className="flex justify-between items-center pt-2 border-t border-accent/20">
    <span className="font-semibold text-sm text-foreground">Всего:</span>
    <span className="font-bold text-accent text-2xl">
      {formatPrice(priceCalc.finalPrice)}
    </span>
  </div>
</div>
```
