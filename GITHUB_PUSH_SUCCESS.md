- Найдите проект MM05
- Проверьте статус деплоя

### Railway (Backend)
Backend НЕ деплоится автоматически. Нужно:

1. Открыть Railway Dashboard
2. Найти проект MM05 Backend
3. Нажать "Deploy" или настроить auto-deploy
4. Добавить SMTP переменные:
   ```
   SMTP_HOST=smtp.sendgrid.net
   SMTP_PORT=587
   SMTP_SECURE=false
   SMTP_USER=apikey
   SMTP_PASS=SG.your-api-key
   SMTP_FROM=MM05 Мебель <noreply@mm05.ru>
   ```
