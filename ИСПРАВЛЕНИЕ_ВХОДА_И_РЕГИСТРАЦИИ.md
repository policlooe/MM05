## 🐛 Найденные проблемы

### Проблема 1: Нет глазка для показа пароля
**Описание:** При вводе пароля невозможно увидеть, что именно вводишь.

**Решение:** Добавлена кнопка с иконкой глаза (Eye/EyeOff) для переключения видимости пароля.

**Файлы:**
- `src/pages/Login.tsx`
- `src/pages/Register.tsx`

---

### Проблема 2: Отсутствуют autocomplete атрибуты
**Описание:** Браузер показывал предупреждения в консоли:
```
[DOM] Input elements should have autocomplete attributes
```

**Решение:** Добавлены правильные autocomplete атрибуты:
- `email` → `autoComplete="email"`
- `password` (вход) → `autoComplete="current-password"`
- `password` (регистрация) → `autoComplete="new-password"`
- `fullName` → `autoComplete="name"`

---

### Проблема 3: Ошибка подключения к API
**Описание:** 
```
POST http://localhost:3000/api/auth/login net::ERR_CONNECTION_REFUSED
POST http://localhost:3000/api/auth/register net::ERR_CONNECTION_REFUSED
```

**Причина:** Бэкенд не запущен или работает на другом порту.

**Решение:** 
1. Улучшено сообщение об ошибке
2. Добавлена инструкция по запуску бэкенда

#### Login.tsx
```typescript
import { Eye, EyeOff } from 'lucide-react';

const [showPassword, setShowPassword] = useState(false);

<div className="relative">
  <input
    type={showPassword ? "text" : "password"}
    // ...
  />
  <button
    type="button"
    onClick={() => setShowPassword(!showPassword)}
    className="absolute right-3 top-1/2 -translate-y-1/2"
  >
    {showPassword ? <EyeOff /> : <Eye />}
  </button>
</div>
```

## 🚀 Как запустить бэкенд

### Вариант 1: Локальный бэкенд (рекомендуется для разработки)

#### Шаг 1: Перейти в папку backend
```bash
cd backend
```

#### Шаг 2: Установить зависимости (если еще не установлены)
```bash
npm install
```

#### Шаг 3: Настроить .env файл
Создайте файл `backend/.env`:
```env
# Database
DATABASE_URL="postgresql://postgres:[YOUR-PASSWORD]@db.anwqnlswltdqqjmfogvu.supabase.co:5432/postgres"

# JWT
JWT_SECRET="your-super-secret-jwt-key-change-this-in-production"
JWT_REFRESH_SECRET="your-super-secret-refresh-key-change-this-in-production"

# Server
PORT=3000
NODE_ENV=development

# CORS
CORS_ORIGIN=http://localhost:5173,http://localhost:8082

# Email (опционально)
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-email@gmail.com
SMTP_PASS=your-app-password
```

#### Шаг 4: Запустить миграции Prisma
```bash
npx prisma migrate dev
```

#### Шаг 5: Запустить бэкенд
```bash
npm run dev
```

**Результат:** Бэкенд запустится на http://localhost:3000

---

### Вариант 2: Использовать продакшн API

Если у вас уже есть развернутый бэкенд, измените `.env.local`:

```env
# Замените на ваш продакшн URL
VITE_API_URL=https://your-backend.vercel.app/api
```
