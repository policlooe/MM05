## 🎨 Как добавить фотографии для разных цветов

### Шаг 1: Подготовьте фотографии

Сфотографируйте кровать Альмак в 3 цветах:
- Натуральный дуб
- Темный орех
- Белый

### Шаг 2: Загрузите фото в проект

Положите фото в папку `src/assets/`:
```
src/assets/
  ├── bed-almak-natural.jpg
  ├── bed-almak-dark.jpg
  └── bed-almak-white.jpg
```

### Шаг 3: Импортируйте фото в products.ts

Откройте `src/data/products.ts` и добавьте импорты:

```typescript
import bed1 from "@/assets/p-bed-1.jpg";
import bedAlmakNatural from "@/assets/bed-almak-natural.jpg";  // 👈 ДОБАВЬТЕ
import bedAlmakDark from "@/assets/bed-almak-dark.jpg";        // 👈 ДОБАВЬТЕ
import bedAlmakWhite from "@/assets/bed-almak-white.jpg";      // 👈 ДОБАВЬТЕ
```

### Шаг 4: Обновите конфигурацию

Найдите кровать Альмак и замените пути к изображениям:

```typescript
color: {
  label: "Цвет покрытия",
  required: true,
  options: [
    { 
      value: "natural", 
      label: "Натуральный дуб", 
      priceModifier: 0,
      image: bedAlmakNatural,  // 👈 БЫЛО: bed1
      default: true
    },
    { 
      value: "dark", 
      label: "Темный орех", 
      priceModifier: 2000,
      image: bedAlmakDark       // 👈 БЫЛО: bed1
    },
    { 
      value: "white", 
      label: "Белый", 
      priceModifier: 3000,
      image: bedAlmakWhite      // 👈 БЫЛО: bed1
    },
  ],
},
```

### Шаг 5: Сохраните и проверьте

```bash
npm run dev
```

Откройте страницу кровати Альмак и выберите разные цвета - фото должно меняться!

## 🛋️ Как добавить конфигурацию к другим товарам

### Пример: Шкаф «Терек»

1. Откройте `src/data/products.ts`
2. Найдите шкаф (id: "p2")
3. Добавьте `advancedConfiguration`:

```typescript
{
  id: "p2",
  slug: "shkaf-terek",
  name: "Шкаф «Терек»",
  price: 62000,
  
  // 👇 ДОБАВЬТЕ ЭТО
  advancedConfiguration: {
    variants: {
      width: {
        label: "Ширина шкафа",
        required: true,
        options: [
          { value: "120", label: "120 см", priceModifier: -10000 },
          { value: "180", label: "180 см", priceModifier: 0, default: true },
          { value: "240", label: "240 см", priceModifier: 15000 },
        ],
      },
      color: {
        label: "Цвет фасада",
        required: true,
        options: [
          { value: "white", label: "Белый", priceModifier: 0, image: wardrobe, default: true },
          { value: "oak", label: "Дуб", priceModifier: 5000, image: wardrobe },
          // Замените wardrobe на реальные фото когда будут готовы
        ],
      },
    },
    options: {
      mirror: {
        label: "Зеркало на дверце",
        type: "toggle",
        price: 8000,
        description: "Зеркало во весь рост",
      },
      assembly: {
        label: "Сборка шкафа",
        type: "toggle",
        price: 4500,
        description: "Профессиональная сборка",
      },
      delivery: {
        label: "Доставка",
        type: "select",
        required: true,
        options: [
          { value: "pickup", label: "Самовывоз", priceModifier: 0, default: true },
          { value: "city", label: "Доставка по городу", priceModifier: 3000 },
        ],
      },
    },
  },
}
```

4. Сохраните файл
5. Готово! Конфигуратор автоматически появится на странице шкафа

## 🔧 Как убрать или изменить опцию

### Убрать опцию (например, матрас):

```typescript
options: {
  headboard: { /* ... */ },
  assembly: { /* ... */ },
  // mattress: { /* ... */ },  // 👈 ЗАКОММЕНТИРУЙТЕ
  delivery: { /* ... */ },
}
```

### Изменить цену опции:

```typescript
assembly: {
  label: "Сборка мебели",
  type: "toggle",
  price: 5000,  // 👈 БЫЛО 3500, СТАЛО 5000
  description: "Профессиональная сборка на дому",
},
```

### Добавить новый размер:

```typescript
size: {
  label: "Размер спального места",
  required: true,
  options: [
    { value: "140x200", label: "140×200 см (полуторная)", priceModifier: -5000 },
    { value: "160x200", label: "160×200 см (двуспальная)", priceModifier: 0, default: true },
    { value: "180x200", label: "180×200 см (king size)", priceModifier: 8000 },
    // 👇 НОВЫЙ РАЗМЕР
    { value: "200x200", label: "200×200 см (super king)", priceModifier: 15000 },
  ],
},
```

## 📊 Для управления из админки (в будущем)

Сейчас всё настраивается в коде (`src/data/products.ts`).  
Чтобы управлять из админки, нужно:

1. **Применить миграцию БД**:
