# ✅ Расширенная система конфигурации товаров - ГОТОВО

## Что реализовано

### 1. Система конфигурации с изображениями для цветов

✅ **Новые типы** (`src/types/product-configuration.ts`):
- `ProductConfiguration` - полная конфигурация товара
- `VariantGroup` - группа вариантов (размер, цвет)
- `VariantOption` - опция варианта с поддержкой изображений
- `ToggleOption` - опция вкл/выкл (сборка, матрас)
- `SelectOption` - опция выбора (изголовье, доставка)
- `SelectedConfiguration` - выбранная конфигурация пользователя
- `PriceCalculation` - расчет цены с детализацией

✅ **Функции-помощники**:
- `calculatePrice()` - расчет финальной цены
- `getImageForColor()` - получение изображения для выбранного цвета
- `initializeConfiguration()` - инициализация дефолтными значениями
- `validateConfiguration()` - валидация обязательных полей

### 2. Новый компонент конфигуратора

✅ **ProductConfiguratorAdvanced** (`src/components/ProductConfiguratorAdvanced.tsx`):
- Поддержка вариантов с изображениями
- При выборе цвета меняется главное фото товара
- Toggle опции (чекбоксы)
- Select опции (радио-кнопки)
- Детализация цены - показывает из чего складывается итог
- Анимации при выборе (Framer Motion)
- Поддержка disabled состояний
- Мобильная оптимизация

### 3. Интеграция в ProductPage

✅ **Обновлен ProductPage** (`src/pages/ProductPage.tsx`):
- Поддержка двух систем конфигурации (старая + новая)
- Автоматическое определение какой конфигуратор использовать
- Обработчик изменения изображения при выборе цвета
- Обновленная логика добавления в корзину

## Как это работает

### Пример использования:

```typescript
// В src/data/products.ts
{
  id: "p1",
  slug: "krovat-almak",
  name: "Кровать «Альмак»",
  price: 46500,  // Базовая цена
  
  advancedConfiguration: {
    variants: {
      color: {
        label: "Цвет покрытия",
        required: true,
        options: [
          { 
            value: "natural", 
            label: "Натуральный дуб", 
            priceModifier: 0,
            image: bed1,  // 🎨 При выборе меняется фото
            default: true
          },
          { 
            value: "dark", 
            label: "Темный орех", 
            priceModifier: 2000,
            image: bedDark  // 🎨 При выборе меняется фото
          },
        ],
      },
    },
    options: {
      assembly: {
        label: "Сборка мебели",
        type: "toggle",
        price: 3500,
        description: "Профессиональная сборка на дому",
      },
    },
  },
}
```

### Расчет цены:

```
Базовая цена:           46 500 ₽
Размер 180×200:         +8 000 ₽
Цвет "Темный орех":     +2 000 ₽
Изголовье мягкое:       +5 000 ₽
Сборка:                 +3 500 ₽
Матрас:                +15 000 ₽
Доставка + подъем:      +3 500 ₽
─────────────────────────────────
ИТОГО:                  83 500 ₽
```

## Как добавить конфигурацию к другому товару

1. Подготовьте изображения для разных цветов
2. Откройте `src/data/products.ts`
3. Найдите нужный товар
4. Добавьте поле `advancedConfiguration` по примеру кровати Альмак
5. Сохраните файл

Готово! Конфигуратор автоматически появится на странице товара.
