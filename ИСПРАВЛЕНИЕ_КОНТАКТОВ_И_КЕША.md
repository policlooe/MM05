## 🐛 Проблема: Изменения не применяются

### Возможные причины:

#### 1. Кеш браузера
Браузер кеширует JavaScript и CSS файлы. Старая версия остается в памяти.

#### 2. Hot Module Replacement (HMR) не сработал
Vite HMR иногда пропускает изменения, особенно при больших правках.

#### 3. Service Worker
Если установлен PWA, service worker может кешировать старую версию.

#### 4. Несколько вкладок открыто
Другие вкладки могут держать старую версию в памяти.

## ✅ Решения

### Решение 1: Жесткая перезагрузка браузера (Hard Refresh)

#### Windows / Linux:
- **Chrome / Edge:** `Ctrl + Shift + R` или `Ctrl + F5`
- **Firefox:** `Ctrl + Shift + R` или `Ctrl + F5`

#### macOS:
- **Chrome / Edge:** `Cmd + Shift + R`
- **Firefox:** `Cmd + Shift + R`
- **Safari:** `Cmd + Option + R`

**Что делает:**
- Очищает кеш для текущей страницы
- Загружает все файлы заново
- Игнорирует кешированные версии

---

### Решение 2: Очистка кеша через DevTools

#### Шаг 1: Откройте DevTools
- **Windows / Linux:** `F12` или `Ctrl + Shift + I`
- **macOS:** `Cmd + Option + I`

#### Шаг 2: Откройте Network (Сеть)
- Вкладка "Network" / "Сеть"

#### Шаг 3: Очистите кеш
- **Chrome / Edge:**
  1. Кликните правой кнопкой на кнопку обновления (рядом с адресной строкой)
  2. Выберите "Empty Cache and Hard Reload" / "Очистить кеш и жестко перезагрузить"

- **Firefox:**
  1. В DevTools: Settings (⚙️) → Advanced Settings
  2. Включите "Disable HTTP Cache (when toolbox is open)"
  3. Перезагрузите страницу

---

### Решение 3: Полная очистка кеша браузера

#### Chrome / Edge:
1. `Ctrl + Shift + Delete` (Windows) или `Cmd + Shift + Delete` (macOS)
2. Выберите "Cached images and files" / "Изображения и файлы, сохраненные в кеше"
3. Выберите период: "All time" / "Все время"
4. Нажмите "Clear data" / "Удалить данные"

#### Firefox:
1. `Ctrl + Shift + Delete` (Windows) или `Cmd + Shift + Delete` (macOS)
2. Выберите "Cache" / "Кеш"
3. Выберите период: "Everything" / "Все"
4. Нажмите "Clear Now" / "Удалить сейчас"

---

### Решение 4: Режим инкогнито / приватный режим

#### Откройте в приватном режиме:
- **Chrome / Edge:** `Ctrl + Shift + N` (Windows) или `Cmd + Shift + N` (macOS)
- **Firefox:** `Ctrl + Shift + P` (Windows) или `Cmd + Shift + P` (macOS)
- **Safari:** `Cmd + Shift + N`

**Преимущества:**
- Нет кеша
- Нет cookies
- Нет расширений (обычно)
- Чистая среда для тестирования

## 🔧 Для разработчиков: Предотвращение проблем с кешем

### 1. Отключите кеш в DevTools (рекомендуется)

**Chrome / Edge:**
1. Откройте DevTools (`F12`)
2. Network → Settings (⚙️)
3. ✅ Включите "Disable cache (while DevTools is open)"

**Firefox:**
1. Откройте DevTools (`F12`)
2. Settings (⚙️) → Advanced Settings
3. ✅ Включите "Disable HTTP Cache (when toolbox is open)"

### 2. Используйте Vite с флагом --force

```bash
npm run dev -- --force
```

**Что делает:**
- Принудительно пересобирает все модули
- Игнорирует кеш Vite
- Полезно после больших изменений

### 3. Очистите кеш Vite вручную

```bash
# Удалить папку кеша Vite
rm -rf node_modules/.vite

# Или на Windows PowerShell:
Remove-Item -Recurse -Force node_modules/.vite

# Затем перезапустить dev-сервер
npm run dev
```

### 4. Используйте версионирование в URL (для продакшена)

Vite автоматически добавляет хеши к файлам:
```
index-B201pqR1.js  ← хеш меняется при изменении файла
```

Это предотвращает проблемы с кешем в продакшене.
