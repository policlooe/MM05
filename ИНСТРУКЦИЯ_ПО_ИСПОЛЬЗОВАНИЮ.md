# Инструкция по использованию нового конфигуратора

## 🎯 Что изменилось?

### Старый конфигуратор
- ❌ Все секции всегда развернуты
- ❌ Занимает много места
- ❌ Неудобно на мобильных

### Новый конфигуратор
- ✅ Секции сворачиваются/разворачиваются
- ✅ Компактный вид
- ✅ Удобно на всех устройствах
- ✅ Показывает выбранные значения в заголовке

---

## 📱 Как использовать?

### 1. Открыть страницу товара
Перейдите на любой товар с конфигурацией, например:
- Кровать «Альмак»
- Беседка «Хунзах»
- Стол «Сулак»

### 2. Работа с секциями

#### Развернуть/свернуть секцию
Нажмите на заголовок секции (например, "Размер спального места"):
```
┌─────────────────────────────────────┐
│ Размер спального места *        ▼   │ ← Нажмите здесь
└─────────────────────────────────────┘
```

#### Свернутая секция показывает выбранное значение
```
┌─────────────────────────────────────┐
│ Размер спального места * — 160×200  │
└─────────────────────────────────────┘
```

#### Развернутая секция показывает все опции
```
┌─────────────────────────────────────┐
│ Размер спального места *        ▲   │
├─────────────────────────────────────┤
│ ┌─────────────┐ ┌─────────────┐    │
│ │ 140×200 см  │ │ 160×200 см ✓│    │
│ │ -5 000 ₽    │ │ Стандартное │    │
│ └─────────────┘ └─────────────┘    │
│ ┌─────────────┐                     │
│ │ 180×200 см  │                     │
│ │ +8 000 ₽    │                     │
│ └─────────────┘                     │
└─────────────────────────────────────┘
```

### 3. Выбор опций

#### Варианты (размер, цвет)
- Нажмите на нужную опцию
- Выбранная опция подсвечивается акцентным цветом
- Появляется галочка в правом верхнем углу

#### Toggle опции (сборка, матрас)
- Нажмите на кнопку опции
- Выбранная опция подсвечивается
- Цена добавляется к итоговой

#### Select опции (доставка)
- Выберите один из вариантов
- Выбранный вариант подсвечивается

### 4. Итоговая цена

#### Свернутый вид (по умолчанию)
```
┌─────────────────────────────────────┐
│ Итоговая цена          Детали       │
│ Всего: 73 000 ₽                     │
└─────────────────────────────────────┘
```

#### Развернутый вид (нажмите "Детали")
```
┌─────────────────────────────────────┐
│ Итоговая цена          Скрыть       │
├─────────────────────────────────────┤
│ Базовая цена           65 000 ₽     │
│ Размер: 160×200 см     Стандартное  │
│ Цвет: Натуральный дуб  Стандартное  │
│ Сборка мебели          +2 000 ₽     │
│ Доставка по городу     +2 000 ₽     │
├─────────────────────────────────────┤
│ Всего: 73 000 ₽                     │
└─────────────────────────────────────┘
```

## 🔧 Для разработчиков

### Компонент
```typescript
import { ProductConfiguratorCollapsible } from "@/components/ProductConfiguratorCollapsible";

<ProductConfiguratorCollapsible
  basePrice={product.price}
  configuration={product.advancedConfiguration}
  defaultImage={product.image}
  onConfigChange={handleAdvancedConfigChange}
  onImageChange={handleImageChange}
/>
```

### Состояние секций
По умолчанию все секции развернуты. Состояние хранится в:
```typescript
const [expandedSections, setExpandedSections] = useState<Record<string, boolean>>({
  'variant-size': true,
  'variant-color': true,
  'option-assembly': true,
  'option-delivery': true,
  'price-details': false, // Детализация цены свернута
});
```

### Переключение секции
```typescript
const toggleSection = (sectionKey: string) => {
  setExpandedSections(prev => ({
    ...prev,
    [sectionKey]: !prev[sectionKey],
  }));
};
```

## 🐛 Возможные проблемы

### Секция не разворачивается
**Причина:** JavaScript ошибка  
**Решение:** Проверьте консоль браузера (F12)

### Цена не пересчитывается
**Причина:** Неправильная конфигурация товара  
**Решение:** Проверьте `product.advancedConfiguration` в `src/data/products.ts`

### Анимация тормозит
**Причина:** Слабое устройство  
**Решение:** Уменьшите `duration` в `motion.div`
