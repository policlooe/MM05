## 🧪 ТЕСТИРОВАНИЕ

### Сценарий 1: Товар с конфигурацией
1. Открыть товар с `configuration` (например, "Кровать «Альмак»")
2. Выбрать размер, цвет, изголовье
3. Включить опцию "Сборка"
4. Проверить, что цена обновилась
5. Добавить в корзину
6. Открыть корзину
7. ✅ Проверить:
   - Отображаются выбранные варианты
   - Отображается "✓ Сборка: +X ₽"

## 🚀 СЛЕДУЮЩИЕ ШАГИ

### Для добавления конфигурации к товару:

1. Открыть `src/data/products.ts`
2. Добавить поле `configuration` к товару:

```typescript
{
  id: "sofa-01",
  name: "Диван Premium",
  price: 50000,
  // ... остальные поля
  configuration: {
    variants: [
      {
        id: "color",
        label: "Цвет",
        type: "color",
        required: true,
        options: [
          { value: "black", label: "Черный", priceModifier: 0 },
          { value: "white", label: "Белый", priceModifier: 2000 },
        ],
      },
    ],
    options: [
      {
        id: "assembly",
        label: "Сборка мебели",
        description: "Профессиональная сборка на дому",
        type: "toggle",
        price: 3500,
        defaultValue: false,
      },
    ],
  },
}
```
