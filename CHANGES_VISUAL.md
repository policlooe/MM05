## 💾 СИСТЕМА ХРАНЕНИЯ (CART STORE)

### ❌ БЫЛО:
```typescript
type CartItem = {
  id: string;
  name: string;
  price: number;  ← только базовая цена
  qty: number;
}

// Цена пересчитывалась каждый раз
total = items.reduce((s, i) => s + i.qty * i.price, 0)
```

### ✅ СТАЛО:
```typescript
type CartItem = {
  id: string;
  name: string;
  basePrice: number;           ← базовая цена
  finalPrice: number;          ← итоговая цена (ВСЕГДА используется)
  qty: number;
  configuration?: {            ← полная конфигурация
    variants: { ... },
    options: { ... }
  };
  assemblySelected?: boolean;  ← для UI
  assemblyPrice?: number;      ← для UI
}

// Цена НЕ пересчитывается, используется finalPrice
total = items.reduce((s, i) => s + i.qty * i.finalPrice, 0)
```

**Изменения:**
- ✅ Сохраняется полная конфигурация
- ✅ Сохраняется итоговая цена
- ✅ Цена НЕ пересчитывается (используется сохраненная)
- ✅ Сохранение в localStorage
- ✅ Разные конфигурации = разные позиции

## 🔄 ПОТОК ДАННЫХ

### ❌ БЫЛО:
```
ProductPage
    ↓
  [Товар]
    ↓
  add(product)  ← только базовая информация
    ↓
  Cart
    ↓
  price = product.price  ← всегда базовая цена
```

### ✅ СТАЛО:
```
ProductPage
    ↓
  [Товар]
    ↓
  ProductConfigurator
    ↓
  selectedConfig + finalPrice  ← полная конфигурация
    ↓
  add(product, config, finalPrice)
    ↓
  Cart (localStorage)
    ↓
  CartItem {
    configuration: {...},
    finalPrice: 53500
  }
    ↓
  CartSidebar
    ↓
  Отображение:
  - Варианты (size: king, color: white)
  - Опции (✓ Сборка: +3 500 ₽)
  - Цены (50 000 ₽ → 53 500 ₽)
```

**Изменения:**
- ✅ Конфигурация передается через всю цепочку
- ✅ Цена рассчитывается один раз (в конфигураторе)
- ✅ Корзина сохраняет итоговую цену (не пересчитывает)
- ✅ UI отображает все параметры
