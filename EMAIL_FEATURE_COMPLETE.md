## 🔧 Как это работает

### 1. Создание заказа
```
Клиент оформляет заказ
    ↓
Backend создает заказ в БД
    ↓
Email сервис проверяет доступность
    ↓
Если SMTP настроен → отправляет email
    ↓
Если SMTP не настроен → пропускает (graceful)
    ↓
Возвращает успешный ответ клиенту
```

### 2. Оплата через Stripe
```
Клиент оплачивает через Stripe
    ↓
Stripe отправляет webhook
    ↓
Backend обновляет статус заказа
    ↓
Email сервис отправляет подтверждение
    ↓
Клиент получает email
```

### 3. Обновление статуса
```
Админ меняет статус заказа
    ↓
Backend обновляет заказ в БД
    ↓
Email сервис отправляет уведомление
    ↓
Клиент получает email с новым статусом
```

## 🎯 Особенности реализации

### Graceful Degradation
Email сервис **опционален** - если SMTP не настроен:
- ✅ Система работает нормально
- ✅ Заказы создаются
- ✅ Оплата проходит
- ⚠️ Email не отправляются (логируется warning)

**Проверка:**
```typescript
if (emailService.isAvailable()) {
  // Отправляем email
} else {
  // Пропускаем
}
```

### Обработка ошибок
Email ошибки **не прерывают** основной процесс:
```typescript
try {
  await emailService.sendOrderConfirmation({...});
} catch (emailError) {
  console.error('Failed to send email:', emailError);
  // Не бросаем ошибку - продолжаем работу
}
```

### Безопасность
- ✅ SMTP credentials в environment variables
- ✅ Не логируются в консоль
- ✅ Не отправляются клиенту
