## Технические детали

### CSS класс для скрытия:
```tsx
className="hidden lg:flex flex-col bg-surface border border-border rounded-xl p-6 shadow-sm"
```

- `hidden` - скрыт по умолчанию (мобильные)
- `lg:flex` - показывается на больших экранах (≥ 1024px)

### Breakpoints:
- **Мобильные**: < 1024px (блок скрыт)
- **Десктоп**: ≥ 1024px (блок виден)
