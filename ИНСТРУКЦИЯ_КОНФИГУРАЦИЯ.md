# 🎨 Инструкция: Как добавить конфигурацию к товару

## Что сделано

✅ Создана система конфигурации с изображениями для цветов  
✅ При выборе цвета меняется фото товара  
✅ Все опции (размер, цвет, изголовье, матрас, доставка)  
✅ Детализация цены - видно из чего складывается итог  
✅ Кровать Альмак уже настроена как пример  

---

## Как это работает

### 1. Загрузите фото товара в разных цветах

Например, для кровати нужно 3 фото:
- `bed-natural.jpg` - натуральный дуб
- `bed-dark.jpg` - темный орех  
- `bed-white.jpg` - белый

Положите их в папку `public/images/` или `src/assets/`

### 2. Откройте файл `src/data/products.ts`

Найдите нужный товар и добавьте поле `advancedConfiguration`:

```typescript
{
  id: "p1",
  slug: "krovat-almak",
  name: "Кровать «Альмак»",
  price: 46500,  // Базовая цена
  image: bed1,
  
  // ДОБАВЬТЕ ЭТО:
  advancedConfiguration: {
    variants: {
      // РАЗМЕР
      size: {
        label: "Размер спального места",
        required: true,
        options: [
          { value: "140x200", label: "140×200 см (полуторная)", priceModifier: -5000 },
          { value: "160x200", label: "160×200 см (двуспальная)", priceModifier: 0, default: true },
          { value: "180x200", label: "180×200 см (king size)", priceModifier: 8000 },
        ],
      },
      
      // ЦВЕТ (с изображениями!)
      color: {
        label: "Цвет покрытия",
        required: true,
        options: [
          { 
            value: "natural", 
            label: "Натуральный дуб", 
            priceModifier: 0,
            image: bed1,  // 👈 ПУТЬ К ИЗОБРАЖЕНИЮ
            default: true
          },
          { 
            value: "dark", 
            label: "Темный орех", 
            priceModifier: 2000,
            image: bedDark  // 👈 ПУТЬ К ИЗОБРАЖЕНИЮ
          },
          { 
            value: "white", 
            label: "Белый", 
            priceModifier: 3000,
            image: bedWhite  // 👈 ПУТЬ К ИЗОБРАЖЕНИЮ
          },
        ],
      },
    },
    
    options: {
      // ИЗГОЛОВЬЕ (выбор из списка)
      headboard: {
        label: "Изголовье",
        type: "select",
        required: true,
        options: [
          { value: "standard", label: "Стандартное", priceModifier: 0, default: true },
          { value: "soft-fabric", label: "Мягкое (ткань)", priceModifier: 5000 },
          { value: "soft-leather", label: "Мягкое (кожа)", priceModifier: 12000 },
        ],
      },
      
      // СБОРКА (вкл/выкл)
      assembly: {
        label: "Сборка мебели",
        type: "toggle",
        price: 3500,
        description: "Профессиональная сборка на дому",
        default: false,
      },
      
      // МАТРАС (вкл/выкл)

        label: "Добавить матрас",
        type: "toggle",
        price: 15000,
        description: "Ортопедический матрас",
        default: false,
      },
      
      // ДОСТАВКА (выбор из списка)
      delivery: {
        label: "Доставка и подъем",
        type: "select",
        required: true,
        options: [
          { value: "pickup", label: "Самовывоз", priceModifier: 0, default: true },
          { value: "city", label: "Доставка по городу", priceModifier: 2000 },
          { value: "floor5", label: "Доставка + подъем до 5 этажа", priceModifier: 3500 },
          { value: "floor5plus", label: "Доставка + подъем выше 5 этажа", priceModifier: 5000 },

  },
```

## Как убрать опцию

Просто удалите её из конфигурации. Например, чтобы убрать матрас:

```typescript
options: {
  headboard: { /* ... */ },
  assembly: { /* ... */ },
  // mattress: { /* ... */ },  // 👈 ЗАКОММЕНТИРУЙТЕ или удалите
  delivery: { /* ... */ },
}
```

---

## Как изменить цену опции

Просто измените значение `price` или `priceModifier`:

```typescript
assembly: {
  label: "Сборка мебели",
  type: "toggle",
  price: 5000,  // 👈 БЫЛО 3500, СТАЛО 5000
  description: "Профессиональная сборка на дому",
},
```

---

## Как добавить новый цвет

1. Загрузите фото товара в новом цвете
2. Добавьте в массив `options`:

```typescript
color: {
  label: "Цвет покрытия",
  required: true,
  options: [
    { value: "natural", label: "Натуральный дуб", priceModifier: 0, image: bed1, default: true },
    { value: "dark", label: "Темный орех", priceModifier: 2000, image: bedDark },
    { value: "white", label: "Белый", priceModifier: 3000, image: bedWhite },
    // 👇 НОВЫЙ ЦВЕТ
    { value: "black", label: "Черный", priceModifier: 4000, image: bedBlack },
  ],
},
```
