## ❓ ВОПРОСЫ И ОТВЕТЫ

### Q: Как добавить конфигурацию к другому товару?

**A:** Откройте `src/data/products.ts` и добавьте поле `configuration`:

```typescript
{
  id: "product-01",
  name: "Товар",
  price: 50000,
  configuration: {
    variants: [
      {
        id: "color",
        label: "Цвет",
        type: "color",
        required: true,
        options: [
          { value: "black", label: "Черный", priceModifier: 0 },
          { value: "white", label: "Белый", priceModifier: 2000 },
        ],
      },
    ],
    options: [
      {
        id: "assembly",
        label: "Сборка мебели",
        type: "toggle",
        price: 3500,
      },
    ],
  },
}
```

### Q: Что делать если git push не работает?

**A:** Выполните:
```bash
git pull origin main
git push origin main
```

### Q: Как откатить изменения?

**A:** Выполните:
```bash
git reset --soft HEAD~1  # Откатить коммит, сохранить изменения
```
