## 📝 Важные заметки

### Требования к функции сборки
- Цена сборки должна настраиваться администратором (хранится в `Product.assemblyPrice`)
- НЕ захардкожена в логике
- Состояние переключателя сохраняется в localStorage (`mm05_assembly_<productId>`)
- Цена пересчитывается мгновенно при изменении переключателя
- Информация о сборке отображается в корзине, checkout и счете

### Расширенная система конфигурации
- Поддержка вариантов с изображениями (выбор цвета меняет основное изображение)
- Поддержка toggle опций (чекбокс для сборки, матраса и т.д.)
- Поддержка select опций (радио-кнопки для изголовья, доставки и т.д.)
- Полный расчет цены с детальной разбивкой
- Все опции настраиваются в коде (интеграция с админ-панелью - будущая работа)
- Конфигурация хранится в JSONB поле в базе данных

### Стандарты качества кода
- Использовать try-catch для всех операций localStorage
- Валидировать все пользовательские вводы (slug, поисковые запросы и т.д.)
- Никаких типов 'any' - использовать правильные TypeScript интерфейсы
- Добавлять обработчики ошибок для загрузки изображений
- Удалять дублирующийся код и неиспользуемые импорты
