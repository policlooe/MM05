## 🐛 Найденные проблемы

### Проблема 1: Конфигуратор развернут по умолчанию
**Описание:** Все секции конфигуратора были развернуты при загрузке страницы, что занимало много места.

**Ожидалось:** Все секции должны быть свернуты по умолчанию.

**Исправление:**
```typescript
// БЫЛО:
initial[`variant-${key}`] = true; // Развернуто

// СТАЛО:
initial[`variant-${key}`] = false; // Свернуто
```

**Файл:** `src/components/ProductConfiguratorCollapsible.tsx`

**Результат:** ✅ Теперь все секции свернуты по умолчанию

---

### Проблема 2: Раздел входа в аккаунт не работает
**Описание:** При клике на иконку входа или переходе на `/login` страница не открывалась (404).

**Причина:** В `App.tsx` отсутствовали роуты для `/login` и `/register`.

**Исправление:**
```typescript
// Добавлены lazy imports:
const Login = lazy(() => import("./pages/Login"));
const Register = lazy(() => import("./pages/Register"));

// Добавлены роуты:
<Route path="/login" element={<Login />} />
<Route path="/register" element={<Register />} />
```

**Файл:** `src/App.tsx`

**Результат:** ✅ Страницы входа и регистрации теперь работают
