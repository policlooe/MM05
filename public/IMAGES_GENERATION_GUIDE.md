## 🍎 Apple Touch Icon (180x180px)

### Требования
- ✅ Размер: **180x180 пикселей**
- ✅ Формат: **PNG**
- ✅ Цветовое пространство: RGB
- ✅ Прозрачность: опционально (iOS добавит скругление автоматически)
- ✅ Название: `apple-touch-icon.png`
- ✅ Расположение: `public/apple-touch-icon.png`

### Дизайн рекомендации
- Используйте логотип **MM05** на белом или зеленом (#22c55e) фоне
- Добавьте padding 10-15px от краев
- Убедитесь, что логотип читаем на маленьком размере
- Избегайте мелких деталей

### Композиция
```
┌─────────────────┐
│                 │
│   ┌─────────┐   │
│   │  MM05   │   │  ← Логотип по центру
│   └─────────┘   │
│                 │
└─────────────────┘
  180x180px
```

### Варианты создания

#### Вариант 1: Онлайн генератор (Рекомендуется)
1. https://realfavicongenerator.net/
2. Загрузите логотип или `favicon.svg`
3. Настройте параметры для iOS
4. Скачайте `apple-touch-icon.png`
5. Поместите в `public/`

#### Вариант 2: Figma/Photoshop
1. Создайте артборд 180x180px
2. Разместите логотип MM05 по центру
3. Фон: белый (#FFFFFF) или зеленый (#22c55e)
4. Экспортируйте как PNG
5. Сохраните как `public/apple-touch-icon.png`

#### Вариант 3: Конвертация SVG
```bash
# ImageMagick
convert -background white -resize 180x180 public/favicon.svg public/apple-touch-icon.png

# Или онлайн: https://cloudconvert.com/svg-to-png
```

## 📱 OG Image (1200x630px)

### Требования
- ✅ Размер: **1200x630 пикселей** (стандарт Open Graph)
- ✅ Формат: **JPG** (оптимизированный)
- ✅ Качество: 80-90%
- ✅ Размер файла: < 300KB
- ✅ Название: `og-image.jpg`
- ✅ Расположение: `public/og-image.jpg`

### Дизайн рекомендации
- **Фон:** Белый или градиент с зеленым акцентом
- **Логотип MM05:** В левом верхнем углу или по центру
- **Текст:** "Мебель из массива в Махачкале"
- **Изображение:** Фото качественной мебели (кровать/стол)
- **Цвета:** Белый (#FFFFFF), Зеленый (#22c55e), Черный (#000000)

### Композиция
```
┌──────────────────────────────────────────┐
│  MM05                                    │
│                                          │
│     Мебель из массива                    │
│     в Махачкале                          │
│                                          │
│  [Фото мебели]                           │
│                                          │
│  Доставка по Дагестану                   │
└──────────────────────────────────────────┘
              1200x630px
```

### Варианты создания

#### Вариант 1: Canva (Рекомендуется)
1. https://www.canva.com/
2. Создайте дизайн "Facebook Post" (1200x630px)
3. Используйте шаблон или создайте с нуля:
   - Фон: белый или градиент
   - Логотип MM05 (крупно)
   - Текст: "Мебель из массива в Махачкале"
   - Фото мебели (если есть)
   - Акцент: "Доставка по Дагестану"
4. Экспортируйте как JPG (качество 90%)
5. Сохраните как `public/og-image.jpg`

#### Вариант 2: Figma
1. Создайте Frame 1200x630px
2. Дизайн:
   ```
   - Фон: #FFFFFF
   - Логотип MM05: 200x80px (верх слева)
   - Заголовок: "Мебель из массива" (Inter Bold, 72px)
   - Подзаголовок: "в Махачкале" (Inter Medium, 48px)
   - Фото мебели: 600x400px (справа)
   - Футер: "Доставка по Дагестану" (Inter Regular, 32px)
   ```
3. Экспортируйте как JPG (90%)
4. Сохраните как `public/og-image.jpg`

#### Вариант 3: Photoshop
1. Новый документ 1200x630px, RGB
2. Добавьте элементы дизайна
3. File → Export → Save for Web (JPEG, 80-90%)
4. Сохраните как `public/og-image.jpg`

#### Вариант 4: Онлайн генератор
- https://www.opengraph.xyz/
- https://ogimage.gallery/
- Введите текст и настройте дизайн
- Скачайте готовое изображение

### Текст для OG Image
```
Заголовок: MM05
Основной текст: Мебель из массива в Махачкале
Подзаголовок: Кровати • Шкафы • Столы • Кресла
Футер: Доставка по Дагестану
```

## ✅ Проверка после создания

### Apple Touch Icon
1. Поместите `apple-touch-icon.png` в `public/`
2. Откройте сайт на iPhone/iPad
3. Нажмите "Поделиться" → "На экран Домой"
4. Проверьте, что иконка отображается корректно

### OG Image
1. Поместите `og-image.jpg` в `public/`
2. Проверьте в валидаторах:
   - https://www.opengraph.xyz/url/https://mm05.vercel.app/
   - https://cards-dev.twitter.com/validator
   - https://developers.facebook.com/tools/debug/
3. Отправьте ссылку в Telegram/VK и проверьте превью
