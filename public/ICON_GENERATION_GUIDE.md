# 📱 Инструкция по созданию Apple Touch Icon

## Что нужно сделать

Создать файл `apple-touch-icon.png` размером **180x180 пикселей** для корректного отображения иконки на iOS устройствах.

## Варианты создания

### Вариант 1: Онлайн генератор (Рекомендуется)
1. Откройте https://realfavicongenerator.net/
2. Загрузите ваш логотип или `favicon.svg`
3. Настройте параметры для iOS
4. Скачайте сгенерированный `apple-touch-icon.png`
5. Поместите файл в папку `public/`

### Вариант 2: Figma/Photoshop
1. Создайте артборд 180x180px
2. Разместите логотип MM05 по центру
3. Фон: белый (#FFFFFF) или фирменный цвет
4. Экспортируйте как PNG
5. Сохраните как `public/apple-touch-icon.png`

### Вариант 3: Конвертация SVG
Если у вас есть `favicon.svg`:

```bash
# Используя ImageMagick
convert -background white -resize 180x180 public/favicon.svg public/apple-touch-icon.png

# Или используя онлайн конвертер
# https://cloudconvert.com/svg-to-png
```

## Требования к иконке

- ✅ Размер: 180x180 пикселей
- ✅ Формат: PNG
- ✅ Цветовое пространство: RGB
- ✅ Прозрачность: опционально (iOS добавит скругление автоматически)
- ✅ Название файла: `apple-touch-icon.png`
- ✅ Расположение: `public/apple-touch-icon.png`

## Дизайн рекомендации

### Для MM05:
- Используйте логотип MM05 на белом или зеленом (#22c55e) фоне
- Добавьте небольшой padding (10-15px) от краев
- Убедитесь, что логотип читаем на маленьком размере
- Избегайте мелких деталей

### Пример композиции:
```
┌─────────────────┐
│                 │
│   ┌─────────┐   │
│   │  MM05   │   │  ← Логотип по центру
│   └─────────┘   │
│                 │
└─────────────────┘
  180x180px
```

## Проверка

После создания файла:
1. Поместите `apple-touch-icon.png` в `public/`
2. Откройте сайт на iPhone/iPad
3. Нажмите "Поделиться" → "На экран Домой"
4. Проверьте, что иконка отображается корректно

## Альтернатива (временное решение)

Если нет возможности создать иконку сейчас, можно временно использовать favicon.svg, но iOS может отображать его некорректно.
